评审 Source Class

CURRENT_STATIC_NONCLAIM当前仓库冻结的产品边界。
CURRENT_API_VALUE仅在实际 GET response/capture 中出现后可填值。
ACCEPTED_ARTIFACT_VALUE仅可引用具备 run / artifact 身份的不可变验收值。
UNAVAILABLE_AUTHORITY没有权威值，必须明确显示未建立/等待。
LABEL_ONLY结构、标签、边界说明，不是运行数据。
